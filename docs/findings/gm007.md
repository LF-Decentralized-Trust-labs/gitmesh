| | |
|---|---|
| **Severity** | warning (5 score points; fails the run at the default `--fail-on warning`) |
| **Applies to** | `instructions` and `rule` artifacts in every scope: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursorrules`, `.github/copilot-instructions.md`, `.claude/rules/`, `.cursor/rules/*.mdc`, `.github/instructions/**`, `.clinerules`, `.roo/rules/`, ... including user-scope memory files under `--user` |
| **Message shape** | `<file> is <N> characters, over the 40000-character effective-context threshold (ICSE 2026 context-rot finding: oversized context measurably hurts agent task success); split it or prune stale content.` |

## What it checks

The raw character count of each instruction or rule file against a threshold of 40,000 characters, roughly 10k tokens at the usual four characters per token. Characters are the only deterministic unit that needs no tokenizer; the count is of the file as committed, before any normalization.

Skills, commands and subagent definitions are loaded on demand rather than ambiently and are not measured.

## Why it matters

Context rot is measurable. The ETH Zurich study presented at ICSE 2026 found LLM-generated context files reduced task success by 2-3% while raising cost by 20% or more. An instruction file that outgrows what an agent can attend to is rot by volume: the agent pays for every token and follows fewer of them. AgentLint's I7 check draws the same 40,000-character line, so the two tools agree on where an entry file stops being safe.

## Example

```text
warning
  GM007  CLAUDE.md  CLAUDE.md is 52310 characters, over the 40000-character effective-context threshold (ICSE 2026 context-rot finding: oversized context measurably hurts agent task success); split it or prune stale content.
```

## How to fix

Prune stale sections. Move per-area guidance into scoped rules (`.claude/rules/`, `.cursor/rules/*.mdc` with `globs`, `.github/instructions/*.instructions.md` with `applyTo`, a nested `AGENTS.md` per package) so each agent loads only what applies. Move reference material into skills, which load on demand.

## What it does not report

- **"Too short" or low-quality prose.** Content judgment is agents-lint's and AgentLint's lane; see the [benchmark checklist](/comparisons).
- **Cross-file budgets.** The count is per file; a cross-file token budget is AgentLint I8's.
- **A different threshold.** The threshold is designed to be configurable, but no repository-level setting exists in this release; it arrives with `.gitmesh/workspace.yaml`. Until then 40,000 is fixed.
