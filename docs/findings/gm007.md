| | |
|---|---|
| **Severity** | warning (5 score points; fails the run at the default `--fail-on warning`) |
| **Applies to** | `instructions` and `rule` artifacts in every scope: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursorrules`, `.github/copilot-instructions.md`, `.claude/rules/`, `.cursor/rules/*.mdc`, `.github/instructions/**`, `.clinerules`, `.roo/rules/`, ... including user-scope memory files under `--user` |
| **Message shape** | `<file> is <N> characters, over the 40000-character effective-context threshold (ICSE 2026 context-rot finding: oversized context measurably hurts agent task success); split it or prune stale content.` |

## What it checks

The raw character count of each instruction or rule file against a threshold of 40,000 characters, roughly 10k tokens at the usual four characters per token. Characters are the only deterministic unit that needs no tokenizer; the count is of the file as it is on disk, before any normalization, and counts UTF-16 code units, so most emoji count as two.

Skills, commands and subagent definitions are loaded on demand rather than ambiently and are not measured.

## Why it matters

Instruction files load into every session, so their size is paid on every turn whether or not the content helps. The research on content is sobering: an ETH Zurich study of repository context files ("Evaluating AGENTS.md", arXiv 2602.11988) found that providing them did not generally improve task success while raising inference cost by over 20%. That study did not measure file length, so the size claim in the message goes beyond its result. The 40,000-character line is a judgment call; AgentLint's I7 check draws the same line for entry files.

## Example

```text
warning
  GM007  CLAUDE.md  CLAUDE.md is 52310 characters, over the 40000-character effective-context threshold (ICSE 2026 context-rot finding: oversized context measurably hurts agent task success); split it or prune stale content.
```

## How to fix

Prune stale sections. Move per-area guidance into scoped rules so each agent loads only what applies: `.claude/rules/` files with `paths:` frontmatter (a rule without it loads at startup like `CLAUDE.md`), `.cursor/rules/*.mdc` with `globs`, `.github/instructions/*.instructions.md` with `applyTo`, or a nested `AGENTS.md` per package. Move reference material into skills, which load on demand. Splitting a file without scoping it clears the finding, because the count is per file, but not the cost.

## What it does not report

- **"Too short" or low-quality prose.** Content judgment is agents-lint's and AgentLint's lane.
- **Cross-file budgets.** The count is per file; a cross-file token budget is AgentLint I8's.
- **A different threshold.** The threshold is designed to be configurable, but no repository-level setting exists in this release; it arrives with `.gitmesh/workspace.yaml`. Until then 40,000 is fixed.
