Add the first two risk rules to the GM table (pivot §8.1 item 3, T1.11). `GM001` (error) reports a plaintext secret or token in any MCP config, agent settings, hooks or config file: a format-agnostic line scanner matches vendor token shapes (GitHub, GitLab, OpenAI/Anthropic, Stripe, Slack, AWS, Google, npm, Hugging Face, JWT, private-key PEM, credentials in URLs) anywhere on a line and applies a Shannon-entropy gate to secret-named keys, skipping `${VAR}`/`op://`/placeholder references; findings name the file, line and key and never the value, pinned by a redaction-guarantee test that seeds secrets across JSON, JSONC and TOML and asserts none reaches the findings. Third-party-manager files are scanned too: ADR-004 protects the manager's territory, not a committed token. `GM002` (warning) fires once per agent that can express a `.env` read deny (§10.5) but leaves it exposed: Claude Code without a `Read(…env…)` entry in `permissions.deny`/`ask`, Cursor without a `beforeReadFile` hook, and OpenCode only when `permission.read` explicitly allows `.env` (it denies by default); Copilot (no hard deny), Codex and Antigravity (command/sandbox controls) are excluded. Copilot's JSONC stripper moves into core as `parseJsonc`, which the copilot detector now imports. Four golden cases under `fixtures/risk/` run the whole table.
